SAAS APPLICATION ENGINEERING

Develop the application behind the service.

Software as a Service (SaaS) is software customers access as an ongoing service, commonly through a web application. Product ownership, hosting and operations remain with the product owner.

When engineering support may fit

Teams may need application work when they are developing product workflows, adding API functionality, connecting application data or maintaining an existing codebase.

Engineering capabilities

  • C#/.NET web application development
  • ASP.NET Core backend services and Web APIs
  • SQL Server and MariaDB data access
  • API endpoint development and changes
  • Feature development, maintenance and dependency upgrades

Typical work

Depending on the agreed scope, work may include a web application feature, API endpoint changes, data-access work or maintenance of an existing product. These are examples of engineering work, not a fixed package or delivery promise.
